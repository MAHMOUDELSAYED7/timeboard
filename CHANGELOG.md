## 0.2.0

- Removed `TimeboardSampleData` from the public API (it was demo data only).
- Added repository links and an MIT license.

## 0.1.0

- Month, Week, Day and Agenda views.
- Light and dark themes, `fromSeed` and `copyWith`; every colour, radius and label is adjustable.
- `TimeboardOptions` for layout and behaviour; `eventColors` and `eventBuilder` for custom bookings.
- Responsive: phone, tablet and desktop layouts; large text sizes supported.
- Events indexed by day for fast navigation with thousands of bookings.
